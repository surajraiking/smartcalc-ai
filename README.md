# SmartCalc AI

All-in-one universal calculator, unit converter, finance engine, manufacturing tools, and interactive chess arena built with React and Vite.

## Features Preserved & Ported

- **Universal Engine (`UniversalCalculator`)**:
  - Conversational smart calculator supporting live natural-language arithmetic, percentage, and unit queries.
  - Multi-category universal unit converter (Mass, Length, Volume, Temperature, Time, Speed, Pressure, Power, Energy).
  - Cooler motor manufacturing calculation suite (raw materials, rejection rates, packing boxes, volumes, and costing).
  - Comprehensive Sales & Business Calculator (Quantity, margins, markups, GST breakup, commissions, freight, and break-even).
  - Live currency converter powered by real-time exchange rates (Frankfurter API).

- **Full SmartCalc Suite (`SmartCalc`)**:
  - Interactive Keypad Basic Calculator with memory functions (`MC`, `MR`, `M+`), live calculation previews, and session history.
  - Over 100 specialized calculation and conversion tools spanning Math, Finance, Health & Fitness, Date & Time, Engineering, Digital Data, Electricity, and more.
  - Interactive 2-Player 3D Chess Arena with full piece logic, move indicators, turn management, and pawn promotion.
  - SmartCalc AI Chat with offline math/GST/manufacturing calculations and step-by-step assistance.
  - Creator profile celebrating Suraj Rai with direct social links.

## Running the Web App

```bash
npm install
npm run dev
```

Runs on port 3000 (`http://localhost:3000`).
